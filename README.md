# Student Information System

## Project Description

The Student Information System is a simple Python program that collects basic information about a student and displays it in a well-formatted student information profile.

The project demonstrates the use of Python variables, user input, string concatenation, and basic output formatting.

## Features

* Collects the student's full name
* Collects the student's ID
* Collects the student's programme
* Collects the student's level
* Collects the student's age
* Collects the student's favourite programming language
* Generates a student username using the first three characters of the student's name and Student ID
* Generates a student email by combining the generated username with the fixed domain `@st.ug.edu.gh`
* Generates the output border using string repetition
* Displays all student information in a clear format

## Username Generation

The program takes the first three characters of the student's name and combines them with the Student ID.

For example:

`Monica Mamah` + `22447815`

produces:

`mon22447815`

## Email Generation

The generated username is combined with the fixed university domain:

`mon22447815` + `@st.ug.edu.gh`

produces:

`mon22447815@st.ug.edu.gh`
